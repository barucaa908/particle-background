给界面加一层会呼吸的星空

发布于 2026-08 · 阅读 5 分钟 · 粒子背景

星座连线的粒子背景是科技产品界面里最经典的氛围装饰之一：粒子缓慢漂移， 彼此靠近时自动连出细线，鼠标移过之处粒子微微靠拢、向光标延伸出光弧。

它在视觉上属于「加法中的减法」——不抢内容，只给单调的纯色背景增加一层 纵深与动感。而实现它的核心，不过是一个全屏 canvas 和几十行几何计算。

原理：距离即缘分

每一个粒子都有自己的位置与速度，每一帧更新位置并环绕边界。 连线规则极其简单：两两之间距离小于阈值就画一条透明度随距离衰减的线。

for (i = 0; i < particles.length; i++)
  for (j = i + 1; j < particles.length; j++)
    if (distSq(i, j) < linkDist * linkDist)
      line(i, j, alpha = 1 - dist / linkDist);

氛围层：星云与星尘

再往上叠加两层：缓慢漂移的星云光晕带来色彩深度，细小的星尘则负责闪烁的 细节。鼠标交互让静态的背景活了起来——光标就像一个引力中心。

好的氛围装饰应该像呼吸一样自然：你看得见它，但从不觉得被打扰。

最后，所有绘制都发生在内容层之下，pointer-events 关闭，滚动、点击、 文本选择都不受任何影响——装饰与功能，各行其道。
